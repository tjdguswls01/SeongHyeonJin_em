기능 선언서

단말의 온라인 가능 여부, CVM 지원 범위, 비접촉 처리 특성이 요약되어 들어간다.

조건부 읽기

AFL이 없으면 바로 Card Read Complete로 이동한다. 모든 거래가 레코드 읽기를 요구하지 않는다.

Processing Restrictions와 fDDA

Processing Restrictions

만료일, Application Usage Control, 예외 조건을 검사해 카드 애플리케이션 사용 가능성을 판단한다.

Fast Dynamic Data Authentication

fDDA는 카드가 만든 Dynamic Signature를 검증해 복제·변조 카드 위험을 확인한다. 실패는 거래 결과에 반영한다.

역할: 카드가 제시한 거래 판정을 그대로 신뢰하지 않고 데이터 유효성과 카드 진위를 확인한다.

거래 방향

AAC, ARQC, TC의 차이

AAC

카드가 거래를 오프라인 거절한 결과이다.

ARQC

발급사 온라인 승인이 필요하다는 요청이다. 단말은 승인 메시지를 구성한다.

TC

카드가 오프라인 승인을 나타낸 결과이다. Reader가 오프라인 거래를 지원할 때 사용된다.

주의: Cryptogram 종류는 GPO에서 이미 정해져 돌아오며 단말은 유효성을 검사하고 후속 동작을 선택한다.
