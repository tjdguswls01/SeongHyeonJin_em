Kernel 4가 보는 거래 조합

EMV Mode

ODA, CVM, Risk Management와 Cryptogram으로 오프라인 승인·온라인 요청·거절을 판단한다.

Mag-Stripe Mode

트랙 데이터와 동적 값으로 온라인 승인용 데이터를 만들며 Issuer가 기존 Mag-Stripe 처리 체계를 활용할 수 있게 한다.

Contactless Mobile

Tag 9F71 Mobile CVM Results와 Reader Capability를 함께 확인해 기기 인증 결과를 반영한다.

추가 분기: 단말 구성에 따라 Offline, Partial Online, Delayed Authorisation으로 완료 방식이 달라진다.

Partial Online과 Delayed Authorisation

Partial Online

카드와 Reader의 상호작용은 1st Card Action Analysis에서 끝난다. Issuer 응답을 받아 거래를 승인 또는 거절한다.

Delayed Authorisation

즉시 온라인 연결이 없는 환경에서 첫 GENERATE AC 결과와 구성 정책을 바탕으로 거래를 보관하고 나중에 승인을 요청한다.

공통점: 두 방식 모두 카드에 두 번째 GENERATE AC를 보내는 접촉식 EMV 완료 흐름과 다르다.
